# V - 轻量本地音乐播放器
一款专为 Windows 打造的轻量、纯净本地音乐播放器，无广告、无捆绑，专注于本地音频文件的播放体验。

## 核心功能
- 支持主流音频格式：MP3、FLAC、WAV、AAC、OGG 等；
- 轻量无负担：安装包体积小，启动速度快，不占用后台资源；
- 适配 Windows 全版本：兼容 Windows 10/11（32/64位）；
- 简洁界面：无多余功能，专注音乐播放核心需求；
- 本地文件管理：支持扫描指定文件夹、批量添加音乐。

# V - Lightweight Local Music Player
A lightweight and pure local music player designed for Windows, no ads, no bundling, focusing on the playback experience of local audio files.

## Core Features
- Support mainstream audio formats: MP3, FLAC, WAV, AAC, OGG, etc.;
- Lightweight and burden-free: small installation package size, fast startup speed, no background resource occupation;
- Adapt to all Windows versions: compatible with Windows 10/11 (32/64-bit);
- Simple interface: no redundant functions, focus on the core needs of music playback;
- Local file management: support scanning specified folders and adding music in batches.
